Open-source software

Last updated 21 November 2026

The Encore Cinema TV app is built with open-source software. Thank you to everyone who makes it. This page lists it, with its licences, and gives you the source code the licences ask us to share.

FFmpeg

When your TV or soundbar can't play a film's DTS or Dolby TrueHD soundtrack itself, the app turns it into lossless surround sound using FFmpeg. We include only FFmpeg's DTS and TrueHD (MLP) sound decoders, built from FFmpeg 6.0.1 without any of its GPL parts. That part of FFmpeg is licensed under the GNU Lesser General Public License, version 2.1 or later.

FFmpeg is built into a small library in the app, libffmpegJNI.so, together with the code that connects it to the app's player (from AndroidX Media3, Apache License 2.0). Everything you need to change FFmpeg and build that library again is here:

  • FFmpeg 6.0.1 source code (10 MB, unchanged from ffmpeg.org; SHA-256 9b16b8731d78e596b4be0d720428ca42df642bb2d78342881ff7f5bc29fc9623)
  • The build script: the exact settings we use, built with the Android NDK r26b
  • The connecting code (ffmpeg_jni.cc, Apache License 2.0)

To use a library you've built yourself, replace lib/<your TV's processor type>/libffmpegJNI.so inside the app. If you'd like any of this on a disc or by email instead, write to contact@encoreaudio.co.uk; this offer stands for at least three years after we last release a version of the app with it.
